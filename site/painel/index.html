Este código conecta a oferta selecionada ao seu painel.

Inclua o script abaixo no HTML do quiz, antes de fechar o </body>. O domínio precisa estar cadastrado na oferta.

Identifique as etapas
Em cada tela, adicione data-quiz-step="id-da-etapa" no elemento principal. Use os mesmos IDs e a mesma ordem cadastrados no painel. O script também reconhece main [data-step] dos quizzes recuperados.
<section data-quiz-step="pergunta-1">
  <button data-track-id="sim" data-track-label="Sim">Yes</button>
</section>
Botões e links são registrados automaticamente. Para manter os nomes do painel em português, use data-track-label. Valores durante a digitação não são coletados.
Marque os objetivos
<section data-quiz-step="resultado" data-quiz-result>…</section>
<button data-quiz-lead>Enviar cadastro</button>
<a data-quiz-checkout href="https://seu-checkout.com">Comprar</a>
Marque a conclusão apenas quando o resultado estiver visível. Para contar o objetivo de cadastro, chame QuizAnalytics.lead() após confirmar o envio. Para salvar o contato na aba Leads, use QuizAnalytics.identify, descrito abaixo. Cliques no checkout não confirmam uma venda.
Seu quiz controla as telas por JavaScript?
QuizAnalytics.step('pergunta-1');
QuizAnalytics.click('continuar', 'Continuar');
QuizAnalytics.complete();
Essas chamadas são alternativas à detecção automática. Evite usar as duas formas para o mesmo clique. A coleta respeita Global Privacy Control; bloqueadores ou falhas de rede podem reduzir a cobertura.
Respostas, blocos e leads
QuizAnalytics.answer('pergunta-1', ['sim']);
// Somente após o cadastro ser enviado e validado:
QuizAnalytics.identify({ email, name, marketingConsent: true });
O coletor atual lê automaticamente as respostas e os cadastros já enviados dos quizzes deste projeto. Não captura o que ainda está sendo digitado. Para outras ofertas, use identify depois de validar o envio. Nome e e-mail ficam apenas na aba privada Leads e podem ser exportados em CSV.
<section data-quiz-section="price">Preço e botão de compra</section>
Use price no bloco de preço e IDs estáveis nos demais blocos. O próprio quiz recuperado já possui esses marcadores. Atualize o data-flow do script quando acrescentar, remover ou reordenar etapas: uma nova estrutura e uma nova visita serão criadas, preservando o histórico anterior.
Checkout
Compras ficam como “não conectado” até configurar o provedor e o webhook assinado. Clique no checkout e página de obrigado, sozinhos, não confirmam pagamento.
Teste sem contaminar seus números
Abra o quiz com ?gal_qa=1&utm_source=qa_teste. Em filtros detalhados, escolha “Somente testes QA”, confira a contagem de eventos no banco e use “Apagar somente visitas de teste”. Sem o modo QA explícito, origens começando com qa e robôs são ignorados.
