Este código conecta a oferta selecionada ao seu painel.

Inclua o script abaixo no HTML do quiz, antes de fechar o </body>. O domínio precisa estar cadastrado na oferta.

Identifique as etapas
Em cada tela, adicione data-quiz-step="id-da-etapa" no elemento principal. Use os mesmos IDs e a mesma ordem cadastrados no painel. O script também reconhece main [data-step] dos quizzes recuperados.
<section data-quiz-step="pergunta-1">
  <button data-track-id="sim" data-track-label="Sim">Yes</button>
</section>
Botões e links são registrados automaticamente. Para manter os nomes do painel em português, use data-track-label. Campos digitados não são coletados.
Marque os objetivos
<section data-quiz-step="resultado" data-quiz-result>…</section>
<button data-quiz-lead>Enviar cadastro</button>
<a data-quiz-checkout href="https://seu-checkout.com">Comprar</a>
Marque a conclusão apenas quando o resultado estiver visível. Para leads, prefira chamar QuizAnalytics.lead() após a confirmação de cadastro, em vez de marcar um botão que ainda pode falhar. Cliques no checkout não confirmam uma venda.
Seu quiz controla as telas por JavaScript?
QuizAnalytics.step('pergunta-1');
QuizAnalytics.click('continuar', 'Continuar');
QuizAnalytics.complete();
Essas chamadas são alternativas à detecção automática. Evite usar as duas formas para o mesmo clique. A coleta respeita Global Privacy Control; bloqueadores ou falhas de rede podem reduzir a cobertura.
